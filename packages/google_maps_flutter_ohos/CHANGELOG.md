## 2.12.3

- Initial OpenHarmony (OHOS) implementation of `google_maps_flutter`.
- Stock `GoogleMap` / `GoogleMapController` API on OHOS via the official
  Maps JavaScript API in the native OHOS WebView.
- Markers, polylines, polygons, circles, heatmaps, tile overlays, ground
  overlays, clustering, info windows, styling, gestures and events.
